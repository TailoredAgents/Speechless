# Speechless featured-product artwork inventory

All four featured products use the listed SVG files as their canonical concept artwork. Every displayed garment is a deterministic, fabric-aware composite made from those exact SVG files. The print layer inherits the underlying shirt’s highlights, grain, and folds; no generated photograph is trusted to reproduce garment lettering.
